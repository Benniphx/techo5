Echo project comparison

People often ask how the projects that bring Echo devices and other screens to Home Assistant compare. This page lists what each one covers. It isn't a ranking: each project is good work with its own focus, and the right one depends on your devices and what you want from them.

This page is kept by TECHO5's author, so read it with that in mind. To keep it even, it was built the same way for every project, TECHO5 included: a separate reviewer for each project read only that project's public repos and listed every feature, the rows come from all six lists, and each answer was checked by a second reviewer.

Checked {{CHECKED}}. These projects move fast, so some cells will be out of date soon. Spot something wrong or missing? Open an issue and it will be fixed. Projects are in alphabetical order.
